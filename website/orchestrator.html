Atomic Spec 2.0.0

Требования, которые переживут смену стека.

Полный бизнес-контракт, заменяемая архитектура и исполняемые тесты до реализации. Один атом — одна единица знания.

Установить скиллМиграция на 2.0

Бизнес остаётся

Правила, понятия и AC должны позволять воспроизвести функционал без чтения старого кода. ID сохраняют смысл при переносе.

Архитектура заменяется

Технологии, контракты компонентов и ограничения находятся в отдельном домене. Их можно заменить, сохранив бизнес-гарантии.

Сначала проверяемый контракт. Затем код.

AАналитика
BGherkin
CАвтотесты · RED
DРеализация · GREEN
Gate A — Аналитика

Акторы, правила, инварианты и гарантии без старого кода.

Gate B — Gherkin

Устойчивые AC и конкретные наблюдаемые результаты.

Gate C — Автотесты · RED

Реальный запуск до поведения; причина падения по требованию.

Gate D — Реализация · GREEN

Те же тесты и затронутые регрессии проходят.

После GREEN — приёмка: требование → сценарий → тест → результат. Ошибка среды и skip не являются RED или PASS. Роли может исполнять один агент.

Связь создаётся вместе с кодом

Сначала объявите существующий ID, затем добавьте URI и смысловое пояснение в той же правке. Пример показывает форму ссылки.

# atomic-spec://PAYMENT-001/DR-1
# Повтор оплаты не увеличивает списанную сумму.
def apply_payment():
    ...

Проектный Guard имеет приоритет. Формальный PASS проверяет ссылки в выбранной области; смысл и поведение проверяются отдельно. Atomic Spec Guard

Один скилл, полный процесс

apm install dab512/atomic-spec --target agent-skills

Для закреплённой установки скачайте архив скилла 2.0.0 и распакуйте его в .agents/skills/. Внутри — шаблоны, инструкции ролей и Git Guard без локальных зависимостей.

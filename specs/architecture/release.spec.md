## Intent

Поставлять проверяемый версионный комплект методологии и скилла.

### DR-1. Самостоятельная поставка

Архив исходников и ZIP скилла извлекаются независимо. Зависимости, локальные данные,
бинарники платформы и кеши исключены. SHA256SUMS фиксирует полученные байты.
Повторная сборка тех же входов даёт те же архивы.

### DR-2. Целостность

Версии пакетов совпадают; реестр разрешается; локальные ссылки ведут к существующим
файлам. Vendored Guard совпадает с закреплённым снимком по SHA-256. Изменение исходника
или сломанная ссылка останавливают подготовку до публикации.

### DR-3. Границы действий

Локальные check/build не выполняют push, release или deployment. Публикация выполняется
отдельно по поручению пользователя и проверяется чтением удалённых артефактов.

### AC-1. Установка скилла

```gherkin
Scenario: Независимый архив
  Given скилл извлечён в отдельный временный каталог
  When launcher проверяет исходник Python с JSON-политикой
  Then существующий AC разрешается без Arc и без установки зависимостей
```

### AC-2. Повреждённый источник

```gherkin
Scenario: Отказ подготовки
  Given изменён файл закреплённого Guard
  When выполняется build
  Then публикационные артефакты не создаются
```
